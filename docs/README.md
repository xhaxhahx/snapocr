## 维护约定

1. **编号即顺序**：`NN-主题.md`，新增文档顺延编号；`licenses.md` 与目录索引不编号。
2. **改 UI 必须同步 `03`**：用户可见行为（按钮、快捷键、默认值、提示文案）变更时，
   同一提交内更新 `03`，并在 `05` 记录。
3. **计数只有一个来源**：探针/单测数量以 `gate.py` 实际输出为准，改计数时全局搜索
   `修复项探针`、`单元测试` 一并更新（`04/06/07/10`、`README`）。
4. **失效引用零容忍**：文档互相引用用相对路径；文档改名必须同步全仓搜索替换。

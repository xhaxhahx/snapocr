## 2. 功能清单（本期冻结）

- 托盘常驻：左键点击=立即框选；右键菜单：截屏/设置/开机自启/退出。
- 全局热键（默认 `F4`，可改），双通道（托盘 + 热键 + `--capture` 命令行）。
- 框选：暗色遮罩、十字光标、放大镜、实时尺寸提示；松开后 8 向手柄微调、空格移动；Enter/双击确认，Esc 取消。
- 编辑工具条：**OCR识别 / 复制 / 保存 / 画笔 / 涂色(荧光笔) / 文字 / 矩形 / 椭圆 / 箭头 / 马赛克 / 颜色 / 线宽 / 撤销 / 重做 / 取消 / 完成(复制并关)**。
- OCR：RapidOCR 离线引擎，PP-OCRv5 mobile det+cls+rec；结果弹窗可编辑、复制、另存 txt、显示耗时与行数。
- 保存：PNG/JPG 自选，默认时间戳文件名，记住上次目录。
- 设置：热键、自启、默认保存目录、OCR 方向分类开关、小字放大倍数、线程数、界面语言。
- 稳定性：单实例、异常日志（`%APPDATA%/SnapOCR/logs`，Linux `~/.local/state/snapocr/logs`）。


## 4. 质量与验收口径

1. **性能**（2 核 4GB 实机）：托盘常驻内存 ≤120MB；热键呼出到遮罩出现 ≤150ms；二次 OCR（1024×512 区域）≤1.5s；冷启动（安装版）≤3s。
2. **正确性**：中文/英文/混排样张识别可用；马赛克后OCR不出底图原文；撤销后画布与原始一致。
3. **健壮性**：OCR 模型缺失/损坏给出中文错误提示而非崩溃；多屏拔插、DPI 切换不崩；热键冲突时提示并可改。
4. **打包**：绿色版在无 Python 的干净 Windows 用户目录解压即用；安装版含卸载器、可选自启与桌面图标，per-user 免管理员。

## 6. 回滚与降级

- OCR 引擎失败 → 结果窗口显示错误与重试按钮，不影响截图功能。
- Wayland 热键失败 → 自动仅保留托盘点击，托盘菜单提示设置系统快捷键方法。
- 模型升级路径：替换 `resources/models/*.onnx` 即可（v6 发布后零代码升级）。

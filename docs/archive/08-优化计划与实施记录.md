# 优化计划书与实施记录（定稿后代码审查轮）

> 原则：**不改变任何定稿的界面与用户可见行为**；每项优化均可回归验证（test_plan_probe + selftest + gallery）。

## 1. 全量代码审查结论

逐文件审查（main/app/config/i18n/paths/logger/singleinstance/windowdetect/capture/autostart/hotkey_*/engine/worker/theme/icons/color_popup/preview/pin(已删)/overlay/editor/result/settings/tests）后确认的问题与优化点：

### A. 死代码/冗余（删除）
| # | 位置 | 内容 | 依据 |
|---|---|---|---|
| A1 | paths.py | `have_tool()` 无调用方 | grep 全工程零引用 |
| A2 | capture.py | `crop_physical()` / `qimage_from_pixmap()` 无调用方 | 裁剪已由 overlay._dev_rect 实现 |
| A3 | windowdetect.py | `window_rect_at()` 已被 `descend_rect_at()` 取代 | overlay 仅调用后者 |
| A4 | icons.py | `"pin"` 图钉分支（功能已移除） | grep 零引用 |
| A5 | capture.py | `QStandardPaths`/`os` 残留导入 | 随 A2 |
| A6 | scripts/ | 历史探针脚本（dbg/patch）清理 | 一次性用途已完成 |

### B. 正确性加固（修复）
| # | 位置 | 问题 | 修复 |
|---|---|---|---|
| B1 | overlay.py | `_last_detect_t` 为类属性，多屏多遮罩共享节流时钟 | 移为实例属性（已完成于测试轮） |
| B2 | overlay.py | 快速拖拽零 move 事件时选区丢失 | 释放时用释放点重建（已完成于测试轮） |
| B3 | editor.py | 缩放拖动中每帧重建马赛克底图（全图模糊+缩放） | 120ms 防抖延迟重建，绘制用旧底图过渡 |
| B4 | singleinstance.py | IPC 报文无上限 | 64KB 上限（已完成于测试轮） |
| B5 | editor.py | `_text_pos` 在失焦提交后残留 | 提交即清 `_text_edit`/`_text_pos`（已实现，复核） |

### C. 性能（优化）
| # | 位置 | 问题 | 优化 |
|---|---|---|---|
| C1 | overlay.py | idle 每次鼠标移动全屏 update（十字+放大镜重绘） | 保留（交互必需），确认无重复 update 路径 |
| C2 | engine.py | 每次识别重复 `cv2.resize` 分配 | 保持（量小），不预优化 |
| C3 | app.py | retheme 重建托盘图标 | 保持（低频），可接受 |

> C 类按“测得再优化”原则：当前 2核4GB 实机交互流畅（拖动/缩放实测无卡顿），不做投机优化。

### D. 架构与健壮性（微调）
| # | 内容 |
|---|---|
| D1 | CaptureController 移除遗留 `editor` 字段（编辑器已并入遮罩） |
| D2 | `_restore_windows` 简化为恢复除结果窗外的隐藏窗口 |
| D3 | `QGuiApplication`/未用导入清理（ruff 全量） |

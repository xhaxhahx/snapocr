## 3. 审计方法（可复现）

1. **静态通读**：37 个源码文件逐行阅读；`grep` 交叉验证符号引用（死代码判定）。
2. **探针取证**：对可疑缺陷写一次性探针（`.tmp/`，跑完即删），用**可执行证据**定级，
   不靠推断。本轮取证 2 项（副屏坐标、IPC 分片），证据链见 `docs/12` 对应条目。
3. **官方文档核对**：对技术栈 API 的用法/生命周期，以官方文档文本为准；
   冲突项在 `docs/10` 增补「官方文档优先」条款（本计划 §5）。
4. **门禁基线**：审计前先跑 `scripts/gate.py`（6/6 PASS，16.1s），确保体检对象本身是绿的。
5. **不动产品代码**：本轮只产出指南书；所有修复建议的实施排期待用户审阅后另立轮次。

## 4. 已知边界与风险

- **不覆盖**：`scripts/archive/`（历史探针）、`.venv` 第三方库自身缺陷。
- **副屏/多屏**：开发机为单屏，副屏类问题只能靠**代码推演 + 探针模拟坐标**取证（已做）；
  真机验证需使用者配合，指南中已标注「需真机复核」。
- **Linux 侧**：hotkey/portal 路径无信创真机，仅静态审查 + 失败安全分析。

## 5. 与官方文档冲突的处理声明（已裁定，回写 `docs/10 §4.6`）

| # | 议题 | 内部现状 | 官方文档 | 裁定 |
|---|---|---|---|---|
| 1 | `locale.getdefaultlocale()` | `i18n.py` 用于跟随系统语言 | Python 3.11 起**弃用**，3.15 移除；官方建议 `locale.getlocale()` 等 | 以官方为准：改用 `locale.getlocale(locale.LC_CTYPE)`（Qt 场景优先 `QLocale.system().name()`） |

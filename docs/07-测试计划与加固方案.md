# 测试计划书与加固方案（定稿后全面测试轮）

> 基线：当前定稿行为（截屏流程/编辑工具/OCR 开关/预览/主题跟随）。本轮所有修复只许修 bug 与隐患，**不得改变定稿的界面与用户可见行为**。

## 1. 范围与技术栈风险清单

| 模块 | 技术栈 | 主要风险类别 |
|---|---|---|
| overlay 遮罩 | QWidget 自绘 + 子窗口画布 | 全屏重绘性能、状态机错乱、子控件遮挡 |
| editor 工具条/画布 | QSS 动态主题 + 自定义弹窗 | 弹窗生命周期、None 引用、重复提交 |
| OCR 链路 | QThread + onnxruntime | 线程竞态、按钮状态错乱、异常路径 |
| 单实例 IPC | QLocalServer/Socket | 数据信任、缓冲上限、跨用户 |
| 全局热键 | Win RegisterHotKey / X11 XGrabKey | 注册失败静默、线程事件循环 |
| 窗口/控件识别 | EnumWindows + RealChildWindowFromPoint | DPI 坐标、自身窗口误命中 |
| 主题 | 注册表 + WM_SETTINGCHANGE | 广播风暴、恢复失败 |
| 打包 | PyInstaller + Inno | 误报、文件锁、资源缺失 |

### 3.1 自动化资产（第九轮补充）

| 脚本 | 用途 | 规模 |
|---|---|---|
| `scripts/gate.py`（+ 根目录 `check.bat`） | **一键门禁**：格式 + 静态检查 + 编译 + 单测 + 下方全部探针 | 7 项 |
| `scripts/test_unit.py` | **单元测试**（零依赖 runner，pytest 可收集）：i18n 键对齐/回落、换行三态、配置脏类型、路径兜底、放大镜矩形几何、拆分重导出契约、局部重绘覆盖 | 18 项 |
| `scripts/test_plan_probe.py` | 原测试计划 T1/T2/T4 的崩溃、回归、安全守住项 | 21 项 |
| `scripts/test_fix_probe.py` | 《问题与优化总表》中标注"需修复"条目的行为验证（线程回收、HiDPI WYSIWYG 像素级、单实例三态、设置窗与配置、spec 瘦身过滤、主题渲染、`--exit` 子进程等） | 241 项（其中 2 项依赖"无实例"前置、4 项需 dpr≠1 屏幕，不满足时 `SKIP`） |
| `src/run.py --selftest` | 模型/引擎端到端与主要界面构件 | 11 项 |

> 探针的副作用隔离约定：配置写入重定向到 `.tmp/probe_config.json`；`set_autostart` 在测试中被
> 替换为空操作 —— 探针不得污染用户真实配置与注册表。

**全局前置条件与 `[SKIP]` 约定（第十轮补充）**：部分用例隐含"当前没有 SnapOCR 实例在运行"这一
环境前提（`R2 无实例时返回 NO_INSTANCE`、`P6 无实例 --exit 立即退出`）。这类用例先做**只读探测**
（只建连接、不发送命令），若检测到实例在跑则输出 `[SKIP]` 并计入 `SKIP` 计数，**不判失败、不阻断门禁**。

理由有两条，第二条更关键：
1. 开发时开着托盘程序跑门禁是常态，硬断言会**误报失败**；
2. `try_connect` / `--exit` 会**真的把命令转发给在跑的实例** —— 前者弹出框选遮罩抢焦点，
   后者直接关掉用户正在运行的程序。测试必须无副作用。

因此**禁止**用 `try_connect` 直接做"有没有实例"的探测，必须走 `_instance_running()`。
正常（无实例）运行时这两项仍会真实执行，计数保持 241 项。


> 代码规范以 `pyproject.toml` 的 ruff 配置为准；提交前必须 `check.bat` 全绿。

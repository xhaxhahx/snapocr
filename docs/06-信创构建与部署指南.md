# 信创（UOS / 麒麟）构建与部署指南

> 适用：统信 UOS 20/25（x86_64、ARM64 飞腾/鲲鹏）、银河麒麟 V10 SP1+；需信创系统本机或同级容器构建（PyInstaller 不跨系统交叉打包）。

## 1. 支持矩阵

| 架构 / 系统 | 抓屏 | 全局热键 | 截图+OCR | 打包形式 |
|---|---|---|---|---|
| x86_64 / UOS 20 1070+（X11） | ✅ | ✅ XGrabKey | ✅ | deb |
| x86_64 / 麒麟 V10 SP1（X11） | ✅ | ✅ | ✅ | deb |
| ARM64 / 飞腾-鲲鹏（X11） | ✅ | ✅ | ✅ | deb（arm64） |
| UOS/deepin 25（Wayland） | ✅ 走 portal 授权 | ⚠️ 用 DE 自定义快捷键 | ✅ | deb |
| LoongArch 龙芯 | ⚠️ 需 Loongnix 轮子源，未验证 | 同上 | ⚠️ | 参见 §7 |

## 2. 构建机准备

### 2.1 系统依赖（UOS/麒麟/Debian 系）

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip \
    libgl1 libglib2.0-0 libxkbcommon-x11-0 libxcb-icccm4 libxcb-image0 \
    libxcb-keysyms1 libxcb-render-util0 libxcb-xinerama0 libxcb-shape0 \
    libxkbcommon0 libdbus-1-3 libfontconfig1
```

> 上面这批运行库同时也是 deb 包的 Depends——构建机装好它们，打出的包在目标机上才能通过依赖校验。

### 2.2 获取源码与虚拟环境

```bash
cd ~
mkdir -p build && cd build
# 将整个工程目录拷贝到构建机（U 盘/scp 均可），假定目录名为 截屏ocr工具
python3 -m venv .venv
.venv/bin/pip install --upgrade pip
```

### 2.3 安装依赖（联网机）

```bash
.venv/bin/pip install -r requirements-linux.txt
```

### 2.4 离线安装（目标机不能联网时的标准做法）

在**联网的同架构**机器上下载轮子（与目标机 Python 大版本一致）：

```bash
# x86_64 构建机：
pip download -r requirements-linux.txt \
    -d wheels --only-binary=:all: \
    --platform manylinux2014_x86_64 --python-version 3.9 --implementation cp
# ARM64 构建机：
pip download -r requirements-linux.txt \
    -d wheels --only-binary=:all: \
    --platform manylinux2014_aarch64 --python-version 3.9 --implementation cp
```

目标机（断网）安装：

```bash
.venv/bin/pip install --no-index --find-links=wheels -r requirements-linux.txt
```

> 版本锚点已在 `requirements-linux.txt` 锁定（numpy 1.26.4 / opencv-headless 4.10 / onnxruntime 1.20 / PyQt5 5.15），全部 manylinux2014 兼容，覆盖 UOS/麒麟的 glibc。

## 3. 构建 deb 包

```bash
cd ~/build
# Linux 版 PyInstaller 打包（产物 dist/snapocr-linux64/）
.venv/bin/python -m PyInstaller --noconfirm --clean deploy/snapocr-linux.spec

# 组装 deb（amd64；arm64 构建机上加 --arch arm64）
bash deploy/linux/build_deb.sh --arch amd64
```

产物：`dist/snapocr_1.0.0_amd64.deb`（含 `/opt/snapocr` 程序、`/usr/bin/snapocr` 命令、应用菜单入口）。

自检（构建机可选）：

```bash
.venv/bin/python -X utf8 src/run.py --selftest
```

## 4. 目标机安装（UOS / 麒麟）

```bash
sudo apt install ./snapocr_1.0.0_amd64.deb
# 或双击 deb 用系统“软件包安装器”安装
```

- 安装内容：程序 `/opt/snapocr`、命令 `/usr/bin/snapocr`、应用菜单项「截图工具」；
- 启动：应用菜单点「截图工具」，或终端 `snapocr`；托盘出现线稿相机图标；
- 卸载：`sudo apt remove snapocr`（用户配置在 `~/.config/snapocr/`，卸载保留）。

## 5. 热键与 Wayland 说明

- **X11 会话**（UOS 20 / 麒麟 V10 默认）：全局热键自动生效，默认 `Ctrl+Alt+A`，托盘→设置可改；
- **Wayland 会话**（UOS 25 等新版）：系统安全模型限制全局热键，两种替代：
  1. 直接点托盘图标截屏（无 Wayland 限制）；
  2. 系统设置 → 键盘和语言 → 快捷键 → 添加自定义快捷键，命令填 `snapocr --capture`；
- **截图授权已由 deb 安装时预配置**：`postinst` 检测到 Wayland 会话会自动执行
  `flatpak permission Grant screenshot snapocr`，并通过 `xdg-permission-store` 尽力预授予
  `org.freedesktop.portal.screenshot` 权限；失败不阻塞安装，并打印回退指引。
  若仍无反应，请允许桌面弹出的截图授权对话框，或手动执行上面的 `flatpak permission Grant` 命令。
- 首次在 Wayland 抓屏会弹系统授权对话框，允许一次即可（xdg-desktop-portal）。

## 6. 部署后验证清单

```bash
snapocr --selftest          # 11 项全 PASS（模型/裁剪/撤销/剪贴板等）
ldd /opt/snapocr/SnapOCR | grep -i "not found"   # 不应有缺失库
python3 scripts/test_plan_probe.py    # 21 项回归探针（源码目录内执行）
python3 scripts/test_fix_probe.py     # 244 项修复项探针（无实例在跑时全跑；否则 2 项 SKIP）
```

| 检查项 | 预期 |
|---|---|
| 托盘图标出现、菜单可弹 | ✅ |
| `Ctrl+Alt+A`（或自定义）呼出遮罩 | ✅ |
| 悬停高亮窗口（X11） | ✅ |
| 框选→松手→编辑工具条展开 | ✅ |
| OCR 识别中文/英文样张 | ✅ 离线推理 |
| 复制到剪贴板 / 保存 PNG | ✅ |
| 深浅主题跟随（UOS 深色模式） | ✅ |

## 7. 已知限制与排障

| 现象 | 原因与处理 |
|---|---|
| 启动报 `could not load xcb plugin` | 缺 xcb 运行库：`sudo apt install -f` 或手动补 §2.1 的库 |
| 窗口/托盘不跟随深色主题 | 仅 UOS 个人版深色模式全支持；麒麟部分主题只换窗口不换托盘，属系统行为 |
| Wayland 下遮罩截不到内容 | 先走 portal 授权；仍失败则注销会话切换为 X11 登录 |
| 全局热键无效 | 确认会话类型 `echo $XDG_SESSION_TYPE`；Wayland 用 §5 的自定义快捷键方案 |
| ARM64 上 pip 找不到轮子 | 确认构建命令带 `--platform manylinux2014_aarch64`；飞腾旧机器 glibc < 2.17 需升级系统 |
| 龙芯 LoongArch | PyPI 无官方轮子，需 Loongnix 源自编译 PyQt5/opencv/onnxruntime，未列入验证矩阵 |
| 文字工具默认字体 | 自动取系统应用字体（Noto CJK / 文泉驿微米黑），与系统一致 |

## 8. 多用户/安全

- 单实例 socket 按用户隔离（`/tmp/snapocr.<uid>.instance.v1`），多用户终端互不干扰；
- 运行期零网络请求；配置/日志位于 `~/.config/snapocr/`，不写系统目录。

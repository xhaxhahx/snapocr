# 截图工具 使用说明

## 1. 安装与启动

| 形态 | 方式 | 行为模式 |
|---|---|---|
| 安装版 | 双击 `SnapOCR-1.0.0-win64-setup.exe`，按需勾选桌面图标/开机自启；安装到 `%LocalAppData%\Programs\SnapOCR`，无需管理员 | 常驻托盘 |
| 绿色版 | 解压 `SnapOCR-1.0.0-win64-绿色版.zip` 到任意目录，双击 `SnapOCR.exe` | 常驻托盘 |
| **单文件版** | 直接双击 `SnapOCR-single.exe` | **用完即走**（见下） |
| Linux deb | `sudo apt install ./snapocr_1.0.0_amd64.deb`（或 arm64 包），启动器在应用菜单「截图工具」 | 常驻托盘 |

**单文件版（用完即走）**：双击后**直接进入框选**；当取消框选、或编辑器/结果窗口全部关闭后，
程序**自动退出**，不留托盘、不驻后台。适合偶尔用一次、不想常驻的场景：

- 想让单文件版也常驻：以 `SnapOCR-single.exe --resident` 启动；
- 安装版/绿色版也可临时"用一次即退"：`SnapOCR.exe --once --capture`；
- 单文件版每次启动需解压整包（本机实测 ~2.4s），常驻使用推荐安装版/绿色版。

启动后在**系统托盘**出现应用图标（深色圆角底 + 蓝色虚线取景框 + 白色剪刀，与程序图标一致；
单文件版退出后图标消失）。首次启动会有气泡提示。

## 2. 呼出截屏

- **左键单击托盘图标** → 立即进入框选；
- 全局快捷键（默认 **F4**，可在设置中改为 Ctrl+Alt+X 等）；
- Wayland 桌面（新版 UOS/deepin）下系统限制全局热键：改用托盘点击，或在
  系统设置 → 键盘快捷键 → 自定义，命令填 `/opt/snapocr/SnapOCR --capture`。

## 3. 框选

- 未框选时移动鼠标：**自动识别并高亮所在窗口/控件**（蓝色边框），单击直接选中；按住拖动则手动框选；
- 拖动中带 5 倍放大镜（采样 24px 见方）与实时尺寸提示；
- **松开鼠标自动进入编辑态**：选区可 8 向手柄微调、框内拖动整体移动；
- 「编辑」按钮 = 展开/收起标注工具菜单（画笔/涂色/文字/矩形/椭圆/箭头/马赛克直接画在截图上）；
- `Esc` 取消；**选区外右键 = 取消**（选区内右键只提交输入中的文字）；
- 画笔/涂色/马赛克显示与笔宽同径的圆圈光标；箭头实时从按下点指向鼠标位置。
- 选区内支持 `Ctrl+C` 复制、`Ctrl+S` 保存、`Ctrl+Enter` 直接 OCR。

## 4. 工具条与标注

框选完成后悬浮工具条（**编辑菜单默认展开**）：

| 按钮 | 功能 | 快捷键 |
|---|---|---|
| 编辑 | 展开/收起标注工具菜单（默认展开） | — |
| OCR识别 | 本地识别选区文字（含标注的所见即所得画面；马赛克遮住的内容不会被读出） | Ctrl+Enter |
| 复制图片 | 标注图存入剪贴板 | Ctrl+C |
| 复制为jpg文件 | 标注图**以 JPG 文件形式**复制到剪贴板（弹窗输入文件名，默认 `截图_时间戳.jpg`；粘贴到资源管理器/聊天窗口即得文件；文件暂存系统临时目录，下次启动自动清理） | — |
| 另存为 | PNG/JPG 保存（默认时间戳文件名） | Ctrl+S |
| 取消 | 放弃本次截图 | Esc |

「编辑」展开/收起时第二行工具菜单带**高度动画**（展开向下滑出、收起向上缩回，约 0.2 秒），
第一行按钮的位置与间距**保持不变**，不会随展开/折叠被拉伸或位移。
| 完成 | 打开**预览确认窗**：复制图片 / 复制为jpg文件 / 另存为 / 重试(回到编辑) / 取消（`Ctrl+S` 可另存） | Enter |

**预览确认窗**：窗口配色/边框/圆角与 **OCR 结果窗一致**，明暗主题自动跟随。
**自绘标题栏**：`图钉 | 最小化 | 最大化 | 关闭`（**图钉在最小化左边**，钉住后变强调色）；
标题栏可拖动窗口、双击切换最大化。
**钉住**后结束截图任务时预览窗**保留在屏幕上**，
可继续查看/复制；只有点标题栏 **×** 或「取消」才会关闭它（`Esc`、右键、操作按钮都不会杀掉钉住的窗口）。
**钉住 ≠ 总在最前**：钉住后窗口不再置顶，可以正常被其他窗口遮挡；且**钉住期间再次截图时预览窗不隐藏**。
预览图画布**支持滚轮缩放（1~8 倍）**，放大后可**按住左键拖动**查看细节，窗口缩放时保持原始纵横比、锚定左上角。

标注工具：**画笔 / 涂色(荧光笔) / 文字 / 矩形 / 椭圆 / 箭头 / 马赛克 / 橡皮擦**，
配 8 色色板（**打开时高亮当前色、色谱光标停在当前颜色位置**）与线宽（文字工具时为字号与**字重**：细体/常规/粗体）选择——**画笔颜色跨会话记忆**（记住上次使用的颜色），
**换区域重新框选后颜色/粗细/字号/字体沿用当前选择**，不回默认值；
文字工具的**输入框是透明背景 + 虚线边框**——能看清文字将落在截图上的哪个位置，
不会把下方内容糊住（输入过程中按 `Esc` 取消、`Enter` 确认）；
工具条**左边缘对齐选区左边缘**——切换工具（文字工具会多出字号/字重/字体三个下拉）时
位置不跳动，宽度变化只向右扩展；`Ctrl+Z / Ctrl+Y` 撤销重做，
**「清空」一键清除全部标注**（撤销/重做栈为空时按钮自动置灰）；
「OCR识别」识别**所见即所得的画面**（含标注）：马赛克盖住的内容不会被读出，
画笔/涂色盖住的文字同样识别不到——屏幕上看到什么，OCR 就读什么。
编辑态拖动手柄微调选区时有**像素级放大镜**跟随辅助对齐。
线宽共 4 档：**细 2px / 中 5px / 粗 10px / 加粗 16px**（默认「中」）。七种工具共用同一套
档位——同一档位下画笔、涂色、矩形、椭圆、箭头的线宽与橡皮擦的擦除直径**完全一致**，
马赛克的涂抹触点同样按档位取直径。
画笔/涂色/马赛克/橡皮擦均显示与当前档位同径的圆圈光标（所见即所得）；
橡皮擦按住拖动**局部擦除**接触到的标注像素（不是整条删除）；
箭头从按下点实时指向鼠标位置。

> 选区可**吸附窗口/控件边缘**：拖动或拖手柄时，边缘进入 8px 内会自动对齐到悬停识别到的窗口/控件边框。

截屏过程中按 `F1` 可查看快捷键速查（托盘菜单不再单列此项，快捷键本身在「设置」里修改）。

## 5. OCR 结果窗口

显示识别文本（可编辑），头部为行数/字数/耗时；按钮：复制文本、**复制为TXT文件**（弹窗输入文件名，
默认 `OCR_文本_时间戳.txt`，以文件形式进剪贴板）、**保存**（原「另存为TXT」）、**格式化换行**、重新识别、关闭。
**「复制文本」成功后在窗口内弹出「已复制到剪贴板」提示**；剪贴板被其他程序占用导致失败时，
会如实提示「复制失败」而不是静默（另存 TXT 成功同样有提示）。

### 格式化换行（点击循环切换）

截图文字天然是碎行。点一次 **「格式化换行」** 换一种排版，循环切换；鼠标悬停可看到当前是哪种、
下一次会切成哪种：

| 顺序 | 模式 | 效果 |
|---|---|---|
| 1（默认） | **原图换行** | 每个识别框一行，完整保留截图原本的排版（代码、表格用这个） |
| 2 | **整段** | 不按符号换行，所有行连成一整段，粘到文档里自然重排 |
| 3 | **按句换行** | 在句末标点（`。！？；` / 英文 `. ! ?`）后断行，按句子分段 |

再点一次回到「原图换行」。切换是**即时重排**，不重新识别，也不影响复制/另存的内容。
**默认是「原图换行」**——即所见即所得，与截图排版一致。

**识别过程是分步可见的**（不是一直空白转圈）：

1. 窗口先显示「正在定位文字…」—— 这一步在整张图里找文本框，是耗时最长的一段，此时还没有文字可显示；
2. 定位完成立刻变为「找到 N 处文字，正在识别…」—— 你能马上知道有没有识别到东西；
3. 随后**按阅读顺序（从上到下、同行从左到右）逐行出现**，头部同步显示「识别中 3/8」；
4. 全部完成后恢复为「N 行 / M 字 / 耗时 x.xs」。

> 为什么不是"一个字一个字"蹦出来：模型先整体扫描定位、再逐块识别，识别阶段只占全部耗时的
> 约 1/4，因此逐行出现集中在最后阶段；前面的定位阶段用「找到 N 处文字」来给反馈。

## 6. 设置项

托盘右键 → 设置（**窗口底部有「恢复默认」**，改乱了一键回默认）：

- **截屏快捷键**（如 `Ctrl+Alt+A`、`Ctrl+Alt+Shift+A`）；清空后按「确定」回落到默认快捷键
- **启动**：开机自动启动（托盘静默常驻）；设置失败会明确提示（多被安全软件/组策略拦截）。
  开关状态以**系统实际状态为准**（注册表启动项）：安装时未勾选自启的，程序首次启动会自动
  把开关对齐为关（安装页的选择是唯一事实源，不会被旧配置残留覆盖）
- **OCR 选项**：
  - 自动纠正文字方向（默认开）
  - **识别后释放模型**（默认关）——低配机勾选可省内存，代价是下次识别重新加载稍慢
  - 小字号放大 ×1.0/×1.5/×2.0
  - 识别线程数（0=自动，自动按 CPU 核数封顶，手改配置注入超大值也会被夹取）
- **界面**：默认保存目录、**马赛克块大小**(6–40)、界面语言：中文 / English（新开窗口即时生效）

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 快捷键无响应 | 多为被其他软件占用（QQ/微信等），到设置里换一个 |
| 托盘图标不见了 | 资源管理器异常时托盘会临时不可用；程序仍在后台运行、快捷键仍可用，托盘恢复后图标自动出现 |
| OCR 提示未找到模型 | 确认 `resources/models/` 下有 det/cls/rec 三个 onnx（缺失时引擎会自动回落到包内置模型） |
| 截到全黑图 | 目标窗口可能以管理员身份运行（UIPI）或处于独占全屏/HDR；程序会给出对应提示，按提示提权重启或改用窗口模式 |
| 远程桌面里热键没反应 | RDP 会话下热键常被本地计算机截走，请用托盘图标点击截屏（启动时也会提示） |
| 截图偏亮发白 | 显示器开启了 HDR，可临时关闭 HDR 后重截 |
| 复制后粘贴是空的 | 剪贴板被其他程序占用；程序会重试并**如实提示"复制失败"**，稍后重试即可 |
| Wayland 下框选黑屏/失败 | 首次会弹出系统授权窗口，允许后重试；或回退 X11 会话 |
| 双屏只有一块屏有遮罩 | 在想截的屏上直接框选即可，每块屏都有独立遮罩 |
| 高分屏截图发虚 | 本程序按物理像素 1:1 抓取，不会虚；若系统缩放为 200%，保存的图即为 2 倍尺寸（4K@200% 等超大屏会自动降采样并同步缩放比，逻辑尺寸不变） |

## 8. 数据与隐私

- 配置：`%APPDATA%\SnapOCR\config.json`（Linux `~/.config/snapocr/`）
- 日志：同目录 `logs/snapocr.log`（滚动 512KB×3）
- 程序运行期**不发起任何网络请求**；模型全部本地推理。

## 9. 卸载

- **安装版**：系统「设置 → 应用」或开始菜单卸载。卸载器会自动结束常驻进程，安装目录完整删除；
  你的配置与日志（`%APPDATA%\SnapOCR`）**有意保留**，想要彻底清除可手动删除该目录。
- **绿色版 / 单文件版**：直接删除文件即可（同样会留下 `%APPDATA%\SnapOCR` 配置目录）。

# 铁律（必须遵守）
1. 只读审计；修复一律给 ```diff 最小片段，禁止重写整文件、禁止顺手格式化、禁止重构。
2. **每个问题必须先验证再报告**：给出代码证据（文件:行 + 触发条件）或可复现步骤。逻辑上无法证明、
   我也无法照做的 → 进"待确认"，**不得进入需修复列表**。
3. **测不出来的不改**。无复现路径只记录，不给方案。
4. 优化必须有**明确收益指标与度量方式**（如启动 -Xms、峰值内存 -XMB、单次推理 -Xms、重绘帧数），
   并给出"改了哪里 + 为什么快 + 回归风险"。无指标的空泛优化（"可以加个缓存""建议异步"）一律归入"不建议"。
5. 防御性编程分两类：
   - **必要防御**（未捕获异常导致崩溃/数据损坏/隐私泄漏/资源泄漏）→ 可报；
   - **过度防御**（把不可能发生的情况包 try、重复校验、吞异常掩盖真问题）→ 明确列为"不改"。
   新增防御不得改变正常路径行为、不得新增依赖、不得影响性能热路径。
6. 兼容性问题必须标明**具体平台/版本/形态**，禁止"某些系统可能有问题"这种模糊表述。
7. 区分：真缺陷 / 兼容性风险 / 优化机会 / 防御性缺失 / 无关风格。只处理前四类。

# 边界状态清单（逐项过，命中才报）
- 空与极值：0 字节/0 像素区域、1x1 图、超长文本行、超大截图（4K/8K/多屏拼接）、极窄框选。
- 并发与重入：截图进行中再触发快捷键、OCR 中再次截图、托盘连点、退出时有任务在跑、
  同一 OCR 任务被重复提交、标注撤销/重做在无历史时的边界。
- 中断与异常：截图过程中屏幕锁定/切换用户/拔显示器/分辨率热变更、OCR 中途进程被 kill、
  保存时磁盘满/只读/路径被占用、剪贴板被其他程序锁定。
- 资源与生命周期：模型句柄/session、临时文件、截图缓存、线程与 QObject 跨线程、
  退出后进程残留与句柄泄漏（用任务管理器/handle/lsof 视角描述）。
- 脏输入：非 UTF-8 路径、中文/空格/emoji 路径、超长路径（>260）、网络盘/只读盘、
  损坏或缺模型的目录、权限不足的 per-user 目录、deb 下 /usr/share 只读。
- 数值/坐标：负坐标多屏、混合 DPI、越界框选、缩放不一致导致的标注偏移、马赛克块边界（1px、非整除）。

  deb 安装目录只读、卸载残留、升级覆盖。
- 隐私：任何隐式网络调用（更新/崩溃上报/字体或模型下载/遥测）→ P0。
